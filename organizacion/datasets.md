# Conjuntos de Datos para Propuestas de Proyectos

Este repositorio presenta dos conjuntos de datos que pueden ser utilizados para desarrollar propuestas de proyectos en el curso. Cada conjunto proviene de un estudio reciente y ofrece oportunidades para explorar distintos aspectos del análisis de software, como la gestión de dependencias, la seguridad y la reutilización de componentes.

---

## 1. [Navigating and Exploring Software Dependency Graphs using Goblin](https://hal.science/hal-04777703)

**Descripción:**  
Este conjunto de datos proviene del estudio que presenta **Goblin**, una herramienta diseñada para enriquecer y consultar el grafo de dependencias del ecosistema Maven Central. Facilita la navegación por relaciones entre paquetes, lo que permite realizar análisis sobre el uso y evolución de dependencias en grandes ecosistemas de software.

**Temas posibles para proyectos:**
- Visualización de grafos de dependencias
- Análisis de ecosistemas de software
- Detección de paquetes críticos o altamente reutilizados

---

## 2. [Wild SBOMs: a Large-scale Dataset of Software Bills of Materials from Public Code](https://hal.science/hal-04995784)

**Descripción:**  
Este conjunto de datos contiene una gran colección de SBOMs (Software Bills of Materials) generadas a partir de código fuente público. Ofrece una visión detallada sobre la composición y las dependencias de numerosos proyectos de software.

**Temas posibles para proyectos:**
- Análisis de la cadena de suministro de software
- Identificación de patrones de reutilización de dependencias
- Estudios sobre seguridad y exposición a vulnerabilidades
